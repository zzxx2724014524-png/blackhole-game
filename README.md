# 黑洞入侵 · 网页版 v5（原创素材复刻玩法）

纯静态网页，无需构建。任意静态服务器打开 index.html 即可（需要 http(s)，不能直接双击 file://，因为用了 ES Module）：

    cd blackhole-game && python3 -m http.server 8000   # 然后访问 http://localhost:8000

在线试玩：https://zzxx2724014524-png.github.io/blackhole-game/

- 操作：手机竖屏，底部中央固定摇杆（松手回中）；电脑鼠标指向方向 / WASD / 方向键；Esc 暂停
- 模式：
  - 🏆 闯关模式（默认）：50 关，12 种主题 × 4 种时段；地图 2×2 → 6×6 街区、物件密集；闯关专用成长曲线：约 15 秒能吃房子、前 25–45% 时间能吃最大建筑，之后越吃越大一路吃光；每关 2–4 分钟（自动驾驶清图模拟标定），金币 +2~5 秒；吃到目标%得 1 星，吃光 100% 得 3 星；镜头随成长拉远，洞吃到最终大小时刚好框住全图；进度存本机
  - 经典（2分钟，5个AI，被吃后复活）
  - 大逃杀（7个AI，一条命）
  - 单人（2分钟吞噬城市百分比）
  - 🌊 海底模式：化身海底漩涡，吞鱼群/螃蟹/章鱼/海龟/鲨鱼/鲸鱼长大；水母和更大的生物会蜇伤/撞击你；氧气不断下降，吃气泡续氧，氧气耗尽即结束；珍珠、宝箱、沉船为额外奖励
- 🎨 皮肤商店（v5）：20 款原创黑洞皮肤（彩虹、冰霜、熔岩、樱花、大西瓜、甜甜圈、曲奇、南瓜灯、小猪、海浪、雷电、象棋盘、幽灵、水晶、赛博朋克、星空银河、黄金、光环天使、虚空之王…），动画着色器边缘 + 粒子 + 小装饰；金币钱包存本机：吃金币 +10、过关星星/通关、比赛名次、海底珍珠都能攒金币；商店内可旋转预览、购买、装备，海底漩涡也会换成皮肤配色
- 🏢 叠叠楼物理（v5）：洞在楼下时楼会晃动、向洞口倾斜，然后一层一层慢慢沉下去（移动时楼会因惯性摇摆，晃太猛会倒）；在洞口边缘停留太久楼会整栋倒下，横躺在洞口上把洞堵住（其它东西进不去），来回晃动或等几秒楼会滑进洞里；倒在地上的楼层散落，之后还能再吃；大型建筑也会缓慢下沉，下沉时暂时堵住洞口
- 玩法：叠叠楼、连吃倍率（×1.5/×2/×3/×5）、道具（磁铁/加速/变大）、金色奖励物（×5）、最后 50 秒狂欢时刻（得分×2）
- 性能：无实时阴影（假阴影贴片）、按类型 InstancedMesh + 视锥/距离剔除、单一共享材质 + 程序生成贴图图集、像素比自适应（≤1.5）
- 所有模型、音效、音乐均为程序生成的原创内容；Three.js r170 已内置于 lib/
